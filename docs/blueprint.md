# **App Name**: Yahnu Assistant

## Core Features:

- Natural Language to Code: Utilize a smart AI tool to convert natural language input into Yahnu code.
- Interactive Code Editor: Display an interactive editor where users can write, test, and view the output of Yahnu code.
- Error Handling and Syntax Highlighting: Provide clear error messages and syntax highlighting to help users debug their code.
- Code Export: Allow users to export Yahnu code for use in other projects.

## Style Guidelines:

- Primary color: Use a vibrant purple (#A020F0) to represent intelligence, creativity, and vision.
- Background color: A desaturated purple (#F2E7FF) for a calm and unobtrusive workspace.
- Accent color: A contrasting pink (#FF69B4) to highlight important interactive elements and draw attention to actions.
- Font: 'Inter', a grotesque-style sans-serif with a modern, machined, objective, neutral look, suitable for headlines or body text.
- Use minimalist icons to represent core functionalities, maintaining a clean and intuitive interface.
- Emphasize a split-screen layout where the code editor is prominently displayed alongside the output console.
- Implement subtle animations for interactive feedback to provide users with instant affirmation of their actions.
